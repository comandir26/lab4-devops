# Lab4 DevOps

Автоматизация развёртывания HTTP-сервиса

## Содержимое

- `service.sh` — скрипт HTTP-сервера
- `lab4-service.service` — unit-файл systemd
- `lab4-healthcheck.sh` — скрипт проверки доступности сервиса
- `site.yml` — Ansible playbook для автоматического развёртывания
- `inventory.example.ini` — шаблон инвентаря Ansible
